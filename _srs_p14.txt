Design rule. The profile is loaded once per request and cached. Services ask questions like 
Industry::feature('batch_tracking') or Industry::costingMethod(). They never ask 
Industry::code() === 'pvc_pipes'. If a new industry needs behaviour that no existing flag expresses, add a
new flag — do not add an if on the industry name.
4.4 Dual unit of measure — the most common source of confusion
Several of these industries buy in one unit and sell in another. A pipe factory buys resin in Kg, produces
pipes measured in metres, and invoices the customer in metres but computes freight on Kg. The system
handles this with three ideas:
Concept Meaning and rule
Stock UOM The one unit in which the stock ledger stores quantity for that item. It can never be changed
once a transaction exists for the item. Validation must block the change.
Transaction UOM The unit the user types on a document. Any UOM linked to the item is allowed. The system
converts to stock UOM before writing the ledger.
Conversion factor Stored per item, not globally, because 1 metre of 110 mm pipe is not the same weight as 1
metre of 25 mm pipe. Factor is DECIMAL(18,6) and must be greater than zero.
Both quantities are stored on every transaction line: qty in the transaction UOM and base_qty in the stock
UOM. Reports can then show either. Rounding is applied only at display time, never before the ledger is
written.
