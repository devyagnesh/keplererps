17.4 Appendix D — Open questions to settle before build starts
# Question Why it matters
Q1 Which industry is the pilot customer? The first industry profile gets built and validated first; the rest
follow the same pattern.
Q2 Is multi-branch needed at version 1, or one
plant only?
Branch scoping touches every query. Adding it later is
expensive; leaving it in when unused costs little.
Q3 Is e-invoicing (IRN) required, and through
which GSP?
The GSP contract has a lead time and defines the payload
format.
Q4 Which biometric attendance device is in use?Determines the punch file format for the importer.
Q5 Will accounting stay in T ally, or move fully into
the ERP?
If T ally stays, an export bridge is needed instead of the full
finance module — a significant scope difference.
Q6 Is a native mobile app required, or is a
responsive web app sufficient?
A Flutter client is a separate project with its own API surface
and release cycle.
Q7 What is the expected number of stock
transactions per day?
Determines whether shared hosting is adequate or a VPS is
required from day one.
