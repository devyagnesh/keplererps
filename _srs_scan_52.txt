User stories
US-M10-01 — As a QC Inspector, I want an inspection created automatically when material is received, so
that nothing slips through unchecked.
Acceptance: posting a GRN for an item with "requires inspection" creates a pending inspection, moves stock
to quarantine, and pushes alert N05 to QC.
US-M10-02 — As a QC Inspector, I want the system to tell me the sample size, so that inspection follows our
sampling plan rather than guesswork.
Acceptance: sample size is calculated from the lot quantity using a configurable plan (fixed number,
percentage, or square-root-plus-one), and the plan used is shown on the inspection report.
US-M10-03 — As a Production Planner, I want the next operation blocked until in-process inspection passes,
so that we do not add value to defective material.
Acceptance: operations flagged "QC required" create an inspection on completion; the following operation
cannot be started while the inspection is pending or failed.
US-M10-04 — As a Customer-facing Sales Executive, I want to send a Certificate of Analysis with the
dispatch, so that the customer's incoming inspection is straightforward.
Acceptance: the certificate lists the batch, test parameters, specified limits, actual readings and the pass
result, carries the QC signature image, and can be attached to the WhatsApp dispatch alert.
US-M10-05 — As a QC Head, I want a Pareto chart of defect reasons for the month, so that we fix the biggest
problem first.
Acceptance: defect quantity by reason, sorted descending with a cumulative percentage line, filterable by
item, machine, shift, operator and supplier.
