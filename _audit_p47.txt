User stories
US-M08-01 — As a Store Keeper, I want to issue material against a work order by scanning a barcode, so
that issuing is fast and accurate.
Acceptance: scanning an item barcode adds a line; scanning a batch barcode selects the batch; the BOM-
suggested quantity is pre-filled and any difference from it must be explained.
US-M08-02 — As an Owner, I want to know the value of stock lying in the factory today, so that I know how
much money is tied up.
Acceptance: a stock valuation report as at any past date, by warehouse, category and item, using the
configured costing method, tallying with the inventory account in the general ledger.
US-M08-03 — As a Store Keeper, I want to do a physical count and post the difference, so that the system
matches reality.
Acceptance: a count sheet is generated and optionally printed with a blank quantity column; counted
quantities are entered or imported; the variance report shows quantity and value difference per item; posting
requires approval above a configurable value and writes an adjustment entry with a reason.
US-M08-04 — As a QC Inspector, I want received material to sit in quarantine until I clear it, so that
unchecked material never reaches production.
Acceptance: quarantine is a system warehouse; its stock is excluded from available quantity; only a QC
acceptance can move it to the main store, and only a QC rejection can move it to the rejection area.
US-M08-05 — As an Owner, I want to see slow-moving and dead stock, so that I can stop buying it and clear
it out.
Acceptance: a report showing items with no movement in a configurable number of days, with quantity, value
and last movement date, exportable.
