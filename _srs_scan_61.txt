Utilities
Utility Behaviour
Data import Downloadable template per master, column mapping that is remembered, dry-run
validation with a row-by-row error report, queued execution, and a summary with a
downloadable error file.
Backup and restore Database dump plus the uploads folder, compressed and optionally encrypted. Manual
button and scheduled cron. Retention count configurable. Restore requires typing the
installation name to confirm.
Update manager Checks for a new version, shows the changelog, takes an automatic backup, puts the site
into maintenance mode, applies files and migrations, clears caches, and rolls back on
failure.
Health check Verifies PHP version and extensions, folder permissions, database connectivity, queue
worker heartbeat, cron last-run time, disk space, and integration credentials. Shown as a
traffic-light panel to Super Admin.
Recycle bin Lists soft-deleted records for 90 days with the ability to restore, subject to permission and
to referential checks.
Bulk operations Bulk price update, bulk item status change, bulk reassignment of a sales executive's
customers — each producing a single summarised activity log entry plus per-record detail.
