7.5.2 Device token lifecycle
Stage Behaviour
Registration On login, the browser or app requests permission and posts the FCM token to POST /api/
devices with device type, model and app version. Stored in user_devices (user_id, token
unique, platform, last_seen_at).
Refresh FCM rotates tokens. The client posts the new token on every app start; the old row is
replaced, matched on the device installation ID.
Cleanup A response of UNREGISTERED or INVALID_ARGUMENT deletes the token immediately. A weekly
job removes tokens unused for 90 days.
Logout / deactivate Deleting the user or setting is_active = false removes all their device tokens in the same
transaction.
