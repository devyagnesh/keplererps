The document link must be a signed, time-limited public URL generated by the ERP (valid 7 days). It
must not require login, must not be guessable, and must be revocable. Meta's servers download the file, so
a link behind the ERP login will fail.
7.4.4 Webhook handling
Meta calls back with delivery status. The ERP exposes GET/POST /api/webhooks/whatsapp:
GET — verification handshake. Compare hub.verify_token with the stored verify token and echo 
hub.challenge.
POST — status updates (sent, delivered, read, failed) and inbound replies. The route is exempt from
CSRF but must verify the X-Hub-Signature-256 HMAC using the app secret. Invalid signature returns 403
and is logged.
Statuses update notification_deliveries.status so the ERP can show a tick mark next to "Invoice sent
on WhatsApp — delivered 15:42, read 16:03".
Inbound replies are stored and shown on the customer's timeline, so a "please send updated proforma"
reply is not lost.
