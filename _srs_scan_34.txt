User stories
US-M02-01 — As a Super Admin, I want to create a user and send them their login details on WhatsApp, so
that onboarding a new staff member takes one minute.
Acceptance: the created user receives a WhatsApp template message with the login URL, username and a
one-time password valid for 48 hours.
US-M02-02 — As a Super Admin, I want to see the full permission list of any user in one screen, so that I can
answer "why can't Ramesh approve this?" without guessing.
Acceptance: an "Effective permissions" view lists every permission the user holds, showing whether it came
from a role or a direct grant, and which role.
US-M02-03 — As a Super Admin, I want to restrict a user to one branch, so that a branch manager cannot
see another branch's data.
Acceptance: every list query, report, dashboard tile and export respects the branch scope; documents from
other branches return 403 on direct access.
US-M02-04 — As a Store Keeper, I want a simple, large-button screen on the shop-floor tablet, so that I can
record issues quickly with dusty hands.
Acceptance: roles can be flagged as "simplified UI", which loads a reduced navigation with larger controls and
only the permitted screens.
