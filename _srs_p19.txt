6. Activity Logging and Audit Trail
6.1 What must be logged
The requirement is simple to state and demanding to implement: every action that changes data, and
every action that reads sensitive data, must leave a permanent record. Three separate logs are
maintained because they answer different questions and have different retention needs.

6.2 Logging rules
# Rule Detail
L1 Logging is automatic A base model trait attaches to model events. A developer adding a
new module gets logging for free by extending the base model.
L2 Never log secrets password, remember_token, two_factor_secret, API keys and
access tokens are on a global ignore list. The list is enforced centrally,
not per model.
L3 Only the difference is stored If a user edits a 60-column record and changes one field, the
properties column holds one old value and one new value — not sixty.
