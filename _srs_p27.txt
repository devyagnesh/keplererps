8. Document and PDF Generation Engine
8.1 Requirements
Every document the factory hands to a customer, supplier or transporter is generated by the ERP . Printed
output is often the most visible part of the software to outsiders, so it must be correct, branded and
configurable without touching code.
Requirement Detail
Engine An HTML-to-PDF renderer driven by Blade templates. Dompdf is the default because it
is pure PHP and needs no binary — essential on shared cPanel hosting. Where the
server allows a binary, a headless Chromium renderer may be enabled in Settings for
better CSS support. T emplates must render acceptably on both.
T emplates are data Each document type has a record in print_templates holding the Blade/HTML body,
paper size, orientation, margins and a flag for which template is the default.
Customers can have several templates for one document type and pick one at print
time.
Safe editing The template editor accepts a restricted syntax — placeholders and simple loops only.
Raw PHP is never evaluated. Placeholders are resolved from a whitelisted data array,
so a template can never read the database directly.
Live preview The editor shows a preview rendered with sample data before saving.
Letterhead handling Three modes: full design printed by the ERP; pre-printed stationery (the ERP leaves
the top 45 mm blank, configurable); or a background image on every page.
Multi-copy T ax invoices print "Original for Recipient", "Duplicate for Transporter", "Triplicate for
Supplier" as separate pages or a single page with the label configurable.
Amount in words Indian numbering (lakh, crore) with configurable currency name. Must handle paise
correctly.
Barcode and QR Code128 and QR generation for labels, e-invoice QR, and item barcodes. Rendered as
inline SVG or base64 PNG, never as an external URL.
Page numbering "Page X of Y" on multi-page documents, with the item table header repeating on each
page and a "carried forward" subtotal.
Digital signature image Optional authorised signatory image and "This is a computer generated document"
footer text.
Storage Generated PDFs for outgoing documents are stored under storage/app/documents/
{year}/{type}/ with a UUID filename, so the same file can be re-sent without
regeneration and the customer sees exactly what was sent.
Performance A 100-line invoice must render in under 3 seconds. Bulk printing of more than 20
documents is queued and delivered as a ZIP through the notification bell.
